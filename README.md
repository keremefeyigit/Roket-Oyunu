# 🚀 HTML5 Roket & Radar Hedef Kilitlenme Oyunu

[![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-yellow.svg)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)
[![HTML5 Canvas](https://img.shields.io/badge/HTML5-Canvas-orange.svg)](https://developer.mozilla.org/en-US/docs/Web/API/Canvas_API)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

HTML5 Canvas ve saf JavaScript kullanılarak geliştirilmiş, 2D dinamik fizik motoru, 360° döner radar sistemi ve kilitlenme efektlerine sahip etkileşimli simülasyon oyunu.

---

## 🎮 Özellikler

- **Gelişmiş Radar Sistemi:** 360 derece döner tarama çizgisi, mesafe halkaları ve gerçek zamanlı dinamik blip takibi.
- **Ekran Dışı Hedef Göstergesi:** Görüş alanı dışındaki hedefler için dinamik vektör okları ve canlı uzaklık göstergesi ($m$).
- **Parazit & Flare Efektleri:** Hedef savunma sistemlerinde radarda oluşan dinamik gürültü/parazit efekti.
- **Sarsıntı & Kilitlenme Fizikleri:** Patlama ve ateşleme anlarında ekran sarsıntısı (Screen Shake) ve yön vektör fizikleri.

---

## 🛠️ Teknolojiler

- **Dil:** Pure JavaScript (ES6+)
- **Çizim Motoru:** HTML5 2D Canvas Context API
- **Stil:** Vanilla CSS3

---

Projede herhangi bir kurulum veya bağımlılık gerekmez.
